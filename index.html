One tool for moving and protecting data

rclone is a command-line utility for managing files across local disks, network shares, and cloud storage. It lets you connect storage services, move data between them, and keep important folders synchronized without installing a large desktop application.

Quick start

Expand-Archive .\rclone-v1.75.2-windows-amd64.zip -DestinationPath .
cd .\rclone-v1.75.2-windows-amd64
.\rclone.exe config
.\rclone.exe copy "C:\Users\Public\Documents" "remote:backups/documents" --progress

Configure an authorized remote first. The Windows package is portable and includes rclone.exe.
